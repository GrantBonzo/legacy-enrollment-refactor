================================================================================
AI PROMPTS USED TO GUIDE THE LEGACY ENROLLMENT PROCESSOR REFACTOR
================================================================================

This file contains the exact prompts used, in order, to guide the AI through
mapping, designing, and incrementally extracting the legacy monolith
(legacy_enrollment_processor.py) into a Clean Architecture split across
domain/, infrastructure/, and presentation/, orchestrated by main.py.

Each prompt follows the RICE format: ROLE, INSTRUCTION, CONTEXT, EXPECTED
OUTPUT. Prompts 1-2 correspond to Assignment Step 1 (Cartographer) and Step 2
(Blueprint). Prompts 3-8 correspond to Assignment Step 3 (Scalpel), extracting
one responsibility at a time. Step 4 (Orchestrator) is completed by Prompt 8,
which finalizes main.py as the clean entry point.

Table of contents:
  Prompt 1 - The AI Cartographer            -> produced ARCHITECTURE.md
  Prompt 2 - The Clean Architecture Blueprint -> produced CLEAN_ARCHITECTURE.md
  Prompt 3 - Extract: SQLite repository      -> infrastructure/sqlite_enrollment_repository.py
  Prompt 4 - Extract: CSV reader             -> infrastructure/csv_enrollment_reader.py
  Prompt 5 - Extract: Email notifier         -> infrastructure/console_email_notifier.py
  Prompt 6 - Extract: Enrollment rules       -> domain/enrollment_rules.py
  Prompt 7 - Extract: Notification messages  -> domain/notifications.py
  Prompt 8 - Extract: HTML report builder    -> presentation/html_report_builder.py
  Prompt 9 - Final orchestration cleanup     -> main.py (composition root)
